| OI-15 | **Lenient time-code flags.** (1) TIME-020 makes CDS sub-ms code `11` `ReservedValue` in every mode, yet `TimeAnomaly::ReservedSubmsCode` (bit 1) makes it a lenient anomaly. (3) `NonZeroDoyHighNibble` (bit 2) has no requirement: 301.0 §3.4.1.2 says the four most significant DOY bits "are not used and are set to zero", which is descriptive, so API-031 does not make it a strict error either. Found in the [`m1/core` review](verification/reviews/m1-core.md), finding 2 | TIME-002, TIME-003, TIME-020, TIME-030, API-031, API-032; `docs/standards/time-codes.md` §7 | **Resolved 2026-10-18 (maintainer):** (1) sub-ms code `11` is `ReservedValue` in both modes (TIME-020); bit 1 is reserved and never raised.
