Copies of fixed-size values (the four OCF octets, a handle's tag and state, `aldis_error_detail_t`) run over a constant length and are not listed. ## Blocking

There is no I/O, locking, atomics, sleep, or spin-wait. `std` is only behind a feature and in test modules; the `no_std` panic handlers (`lib.rs`) are never reached (VER-010). Every inspected function is O(input length) or O(1) by the table above; a TM or AOS call that takes a master channel is O(frame length + `vc_count`), the AOS table adding a constant 64 × 64, a TC call O(frame length + (64 + `ALDIS_TC_MAX_MAPS`)²), and a USLP call O(frame length + (`ALDIS_USLP_MAX_VCS` + `ALDIS_USLP_MAX_MAPS`)²).
