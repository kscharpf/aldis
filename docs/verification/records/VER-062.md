# Record: VER-062

| | |
|---|---|
| Requirements | VER-062 |
| Method | I |
| Check | Review of each pull request that changes [`decision-rights.md`](../../process/decision-rights.md) or records a maintainer decision |

**Inspection.** The reviewer of a pull request whose description has a "Maintainer decisions" section, or that changes an OI, a plan decision, or a requirement on the maintainer's word, checks that the decision sits where the decision rights say, and that no decision §2 of the decision rights gives to the maintainer is taken by the coordinator or an agent. A change to `decision-rights.md` itself carries the maintainer's decision in its description. The decision log (`docs/process/decisions.md` and `cargo xtask decisions`) was removed on 2026-10-30 at the maintainer's request; its history is reachable with `git log -- docs/process/decisions.md`.
