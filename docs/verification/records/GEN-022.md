# Record: GEN-022, GEN-023

| | |
|---|---|
| Requirements | GEN-022, GEN-023 |
| Method | A |
| Check | Verify check `stack` (VER-011); Kani proof harnesses; `#![no_std]` architecture verification |

GEN-022 (bounded loops, no recursion) and GEN-023 (bounded execution time, non-blocking) are verified by analysis (**A**):

1. **Recursion:** The verify check `stack` (record [VER-011](VER-011.md), `xtask/src/stack.rs`) builds the call graphs of the C ABI static library and of the exerciser directly from their object code and LLVM IR for three bare-metal architectures (thumbv7em, armv7r, riscv32imac) and fails on any call cycle. This guarantees that no recursion reaches any library entry point.
2. **Loop Bounds & Termination:** All library code loops over slices, arrays, or ring buffers bounded by slice length, capacity constant `N`, or fixed constant bounds. Complex loops (e.g. CRC table calculations and bitwise updates, Galois OID generation, bit-field manipulation, and `ErrorKind` catalogue lookups) are formally proven bounded by Kani bounded model checking harnesses (`crates/aldis-core/src/proofs.rs`, [formal-proofs.md](../formal-proofs.md) §2).
3. **Execution Time & Non-Blocking (GEN-023):** The library crates are `#![no_std]`, heap-free (GEN-010, GEN-011), and deterministic with sans-I/O engines (GEN-030). There are no operating system syscalls, no blocking I/O, no sleep calls, no threads, and no locks. Every operation finishes in $O(\text{input length} + \text{capacities})$.

**Historical record:** Through releases `v0.2.0-m1` and `v0.3.0-m2`, GEN-022/GEN-023 were tracked via per-crate Markdown inspection records (`docs/verification/inspections/gen-022-023-<crate>.md`) under requirement VER-061. Those inspections were reviewed and approved by the maintainer across milestones M1 and M2 (see git history). On 2026-10-28, VER-061 and the per-PR Markdown inspection tables were retired in favor of automated call-graph analysis (`check:stack`), formal verification, and architectural constraints. `cargo xtask loops [list]` remains available as a diagnostic scanner.
