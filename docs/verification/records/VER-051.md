# Record: VER-051

| | |
|---|---|
| Requirements | VER-051 |
| Method | A |
| Check | Verify check `header`: `cargo xtask header c-tidy` (clang-tidy `cert-*-c`) |

The analyser is clang-tidy of the pinned LLVM (`file:toolchains.lock`), a free tool (VER-055; OI-22). `cargo xtask header c-tidy <clang-tidy>` (`file:xtask/src/header.rs`) runs every `cert-*-c` check, with each finding an error, over every `.c` file of `file:crates/aldis-ffi/tests/c/smoke.c` and its siblings in `crates/aldis-ffi/tests/c/` (the directory is listed when the check runs, so a file added there is covered with no edit) and over the C example of `file:crates/aldis-ffi/README.md`, compiled as C99 against `file:include/aldis/aldis.h`. The verify check `header` and the `header` job of `ci.yml` run it. The checks cover the CERT C rules that clang-tidy implements (DCL03, DCL16, DCL37, ENV33, ERR33, ERR34, EXP42, FIO38, FLP30, FLP37, INT09, MSC24, MSC30, MSC32, MSC33, POS44, POS47, SIG30, STR34, CON36); the other rules of the standard are not checked by any tool of this project.

The native C implementation of VER-051 does not exist yet: the C code in scope is the test and example code. Track C extends the scope when it adds C.
