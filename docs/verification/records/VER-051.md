The analyser is clang-tidy of the pinned LLVM (`file:toolchains.lock`), a free tool (VER-055; OI-22). The check is `cargo xtask header c-tidy` (`file:xtask/src/header.rs`, `c_tidy`): the `cert-*-c` checks of the pinned clang-tidy (`clang-tidy -checks='-*,cert-*-c' -list-checks` lists them) over every `.c` file in `crates/aldis-ffi/tests/c/` and the C example of `file:crates/aldis-ffi/README.md`. The verify check `header` and the `header` job of `ci.yml` run it. Rules of the standard that no `cert-*-c` check implements are checked by no tool of this project.

The native C implementation of VER-051 does not exist yet: the C code in scope is the test and example code. Track C extends the scope when it adds C.
