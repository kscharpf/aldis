every check runs on an unknown change, when no record exists for the base or the branch, or with `--all` (`file:xtask/src/verify/scope.rs`: `sources`, `plan`; tests in `file:xtask/src/verify/scope.rs` with throwaway git repositories, among them a branch that merges a `main` that changed only `docs/` (Rust checks reused) or a Rust input (Rust checks run), a source whose record fails the gate or that is not an ancestor (not used), records of formats 1, 2, and 3 followed to their origin, and a change to the workflows or the pull-request template, which runs only `spec`;
