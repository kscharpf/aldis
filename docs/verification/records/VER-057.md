# Record: VER-057

| | |
|---|---|
| Requirements | VER-057 |
| Method | A |
| Check | `xtask/src/verify/record.rs` and its tests |

`xtask/src/verify/record.rs`: canonical JSON and SHA-256 (tests against a FIPS 180-2 example and fixed records); `cargo xtask verify publish` stores the record under `refs/notes/verify` (`publish.rs`); `cargo xtask verify check <rev>` re-reads a published record, recomputes its SHA-256, and checks its commit, tree, and gate. Records carry `format` `aldis-verify-record/3`: the `scope` of the input rule, and for each `skipped` or `reused` check a `source` with the commit and the SHA-256 of the record its result is taken from; records of format 2 (skips against the base only) and format 1 (the C++ scope `cpp` only) are still read, and a tool that knows only those refuses format 3. A run that stops at a gating failure (`--fail-fast`) records each check it did not reach as `not-run` with the reason, writes the record and the logs locally, and publishes nothing; a run that starts no container records `image.source.kind` `none` with the reason and the hash of the commit's image inputs, and no image ID, tool versions of the image, or packages (`image::unused`; tests in `record.rs` and `mod.rs`)
