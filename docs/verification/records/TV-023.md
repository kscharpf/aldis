# Record: TV-023

| | |

| Requirements | TV-023 |
| Method | A |
| Check | Verify check `spec`: `cargo xtask vectors validate` runs the models |

`cargo xtask vectors validate` (`file:xtask/src/models.rs`) runs `python3 -I test-vectors/models/<name>.py --check <files>` from the repository root for every model that a `provenance_note` names, with the files that name it, and fails when a model exits non-zero, a named model does not exist, or a model in `test-vectors/models/` is named by no file. The verification image installs `python3` (`xtask/verify/Containerfile`). Models on 2026-10-21: `aos_fhec.py` (`test-vectors/aos/fhec_*.json`, 46 cases) and `core_ocf.py` (`test-vectors/core/ocf.json`, 20 cases); each `--check` was shown to fail on a file with one expected value changed. Independence of a model from the code it checks is reviewed in the PR that adds it ([`test-vectors/models/README.md`](../../../test-vectors/models/README.md)).
