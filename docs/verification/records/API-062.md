# Record: API-062

| | |
|---|---|
| Requirements | API-062 |
| Method | I |
| Check | Inspection of the output-area bound in the module docs of the engines of `aldis-link`, 2026-11-04 (M4 exit) |

Each engine states, per input, the largest number of octets it writes to the output area, as a function of its capacities, in the paragraph "Bounds (LNK-074, LNK-075, API-062)" at the top of its module (file:line in `crates/aldis-link/src`; the figures are the ones of the table in `file:docs/04-engines.md` §4):

| Engine | Paragraph | Bound stated |
|---|---|---|
| PacketGenerator | generator.rs:16 | `Release` at most D octets (the data field); other inputs none |
| AccessGenerator | access.rs:11 | `Release` the data field of the VC; other inputs none |
| BitstreamGenerator | bitstream.rs:9 | `Release` the data field of the VC; other inputs none |
| ChannelMux | mux.rs:22 | `Opportunity` the frame length of the configuration; other inputs none |
| MapSegmenter | segmenter.rs:31 | `NextFdu` at most max_fdu_len octets (L), whether or not an FDU is ready; other inputs none |
| CltuPacker | cltu.rs:22 | `AddFrame` at most 2·U octets, `Flush` at most U; `Reconfigure` none |
| FrameReceiver | receiver.rs:23 | `Frame` at most the area_len of the configuration; `RawFrame` the Insert Zone length; `FrameLoss`, `CallerDiscard`, `Reconfigure` none |
| PacketExtractor | extractor.rs:11 | `DataField` at most max_packet_len − 1 + z octets; `Reconfigure` none |
| MapReassembler | reassembler.rs:37 | `Fdu` at most max_sdu_len − 1 + z octets; `Reconfigure` none |

What the inspection looked for, and found:

- Every one of the nine engines has the paragraph, it names the input and the bound, and the bound is a function of the engine's capacities or configuration, not of the input's content.
- The figures agree with the table of `file:docs/04-engines.md` §4 row by row.
- An area shorter than the bound fails the input with BufferTooSmall before any state change (LNK-075, API-058); the tests of that behaviour are traced to those requirements, not to this one.

Redo the inspection in every PR that adds an engine or an input that writes to the output area.
