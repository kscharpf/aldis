# Record: VER-061

| | |
|---|---|
| Requirements | VER-061 |
| Method | I |
| Check | Review of each PR that changes library code; the milestone exit review |

Each pull request that adds or changes a loop, a call between a crate's own functions, or a blocking construct revises the crate's record in [`inspections/`](../inspections/), prepared by its author and pending exit review; the reviewer of the pull request checks that it does. The maintainer approves every pending revision once, at the milestone exit review (exit checklist in [`docs/milestones/checklists.md`](../../milestones/checklists.md)) or before a release, and records it in the `Approved` row. Inspected 2026-10-21, when the rule was adopted: nothing in `xtask/src/` or `.github/` (workflows, pull request template) asks for or checks an approval (`grep -rniE "approv|pending"` finds only an unrelated variable in `xtask/src/binaries.rs`). The first exit under the rule is M2's.
