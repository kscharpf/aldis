# Record: API-050

| | |
|---|---|
| Requirements | API-050 |
| Method | I |
| Check | Inspection of `aldis-cop1` and of the `aldis-ffi` engine functions for caller code, 2026-10-31 (M3 exit) |

The engines take their inputs as data and return their actions as data: the decide, commit, and step functions of `file:crates/aldis-cop1/src/fop1.rs` and `file:crates/aldis-cop1/src/farm1.rs`, and the init, step, deadline, status, and deinit calls of `file:crates/aldis-ffi/src/fop1.rs` and `file:crates/aldis-ffi/src/farm1.rs`.

What the inspection looked for, and found:

- `aldis-cop1` declares no trait, no `dyn`, no `Box`, no function-pointer type, and no generic parameter bounded by `Fn`, `FnMut`, or `FnOnce` in a public or private signature. Its only closure parameter is a private helper of `file:crates/aldis-cop1/src/fop1.rs` that receives a closure written in the same file.
- SDLS is not an engine input as code: `SecurityHook` is not referenced in `aldis-cop1` (OI-56, H5; API-074).
- `file:include/aldis/aldis.h` has no function-pointer typedef or parameter, and no FOP-1 or FARM-1 call takes a callback (CABI-040).
- Every closure on the FFI engine path is library code. The searches were `git grep -F "||"` and `git grep -E "\|[a-z_&, ]+\|"` over `file:crates/aldis-ffi/src/fop1.rs` and `file:crates/aldis-ffi/src/farm1.rs`, `git grep -n "init_with"` over the same files, and `git grep -n "impl Fn\|FnOnce\|FnMut"` over `crates/aldis-ffi/src`, each hit read. The closure parameters are the `call` helper of `file:crates/aldis-ffi/src/abi.rs` (the body of each C entry point), `read`, `update`, and `init_with` in `file:crates/aldis-ffi/src/handle.rs` (the state lent for one call), and a `parse` helper of `file:crates/aldis-ffi/src/tc.rs` outside the engine path. The closures passed to them are written in the two engine files above: the `call` bodies, the `read`, `update`, and `init_with` arguments, a local frame closure in the FARM-1 file, and an `ok_or_else` error constructor in the FOP-1 file. No function takes a closure from a C caller.

Redo the inspection in every PR that adds a public item to `aldis-cop1` or a function to the FOP-1 or FARM-1 files of `aldis-ffi`.
