# Record: RS-002

| | |
|---|---|
| Requirements | RS-002 |
| Method | A |
| Check | Every build and test check; the nightly jobs |

All build and test checks of the verification run, and the nightly native jobs, use the pinned stable toolchain. Nightly, pinned in `tooling-nightly`, is used only by tooling: coverage instrumentation (verify check `coverage`), fuzzing, stack-size emission with `core` built from source (`-Z emit-stack-sizes`, `-Z build-std=core`: the verify check `stack` and the nightly job `stack-sizes`, VER-011), and `-Z build-std` for targets without a prebuilt `core` (`nightly.yml`, and the non-gating verify check `rust-sparc-leon3` for the tier-3 LEON3 target, OI-08). The fuzz crate and the exerciser build and lint on stable; only the exerciser's LEON3 start-up code needs the nightly's `asm_experimental_arch`, enabled for that target alone
