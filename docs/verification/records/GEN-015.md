# Record: GEN-015

| | |
|---|---|
| Requirements | GEN-015 |
| Method | I |
| Check | Review of [hardware assumptions](../../hardware-assumptions.md) |

Review of `docs/hardware-assumptions.md` (2026-10-24, branch `docs/readme-assurance`). It states:
- **The assumption:** memory holding Aldis state between calls is protected against single-event upsets, or does not change at run time. The state named is configurations, engine state, and helper storage.
- **What an upset in unprotected memory does:**
  - an enum with an invalid discriminant is undefined behaviour;
  - a restricted value is not checked again after construction (RS-020);
  - bounds checks still hold (GEN-020);
  - the exposure, by state.
- **What the integrator does:** EDAC with scrubbing; `const` configurations in read-only memory (RS-012); uncorrectable errors as a reset condition; and the mission's own analysis where memory is not protected.

The M2-exit hazard analysis (WP-8) and the M3 plan refer to it. Reviewed again whenever Aldis gains long-lived state, first in M3 (COP-1 engines).
