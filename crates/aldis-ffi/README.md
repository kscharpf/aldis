# aldis-ffi

The C ABI of Aldis: a static and a shared library, `libaldis_ffi`, with the header [`include/aldis/aldis.h`](../../include/aldis/aldis.h) generated by `cbindgen`, for C and C++ applications and for bindings in other languages.

**Status:** the M1 codecs: time codes (`aldis_time_*`), Space Packets (`aldis_spp_*`), and Encapsulation Packets (`aldis_epp_*`), with the stateful SPP helpers in caller-owned storage ([M2 plan](../../docs/milestones/m2-frame-codecs.md) WP-0c, D4, D5). Each frame codec adds its functions in its M2 work package; M3 and M4 add the engines' handles, and M5 completes the ABI with the C test harness and the C++ wrapper `aldis.hpp` ([roadmap](../../docs/08-roadmap.md) §1).

## Where it sits

The foreign-function boundary of the [architecture](../../docs/01-architecture.md) §2, above the layers. It depends on the facade `aldis` with the feature `full`, and builds as `staticlib`, `cdylib`, and `rlib`.

## Conventions

The [C ABI profile](../../docs/profiles/c-abi.md) sets the rules; §10 lists the details the M1 codecs settle.

- Every fallible function returns `int32_t`: `ALDIS_OK` (0) or a negative `ALDIS_ERR_*`, the negated code of the [error catalogue](../../docs/03-api-model.md#9-error-catalogue) (CABI-020). Its last parameter is an optional `aldis_error_detail_t *`, written only on failure, with the kind, the field code (`ALDIS_FIELD_*`, 0 for none), and `needed` or `expected`/`found` (CABI-021).
- Every pointer and length is checked: `NULL` only for an empty buffer or the detail, every pointer aligned, no output overlapping an input. A violation is `ALDIS_ERR_INVALID_FIELD` naming no field (CABI-022).
- Buffers are `(const uint8_t *, size_t)` in and `(uint8_t *, size_t cap, size_t *out_len)` out (CABI-011). Views are POD structs with offset/length pairs into the input (CABI-012). Configuration structs start with `uint32_t struct_size` (CABI-033).
- The decode mode is a `uint32_t` (`ALDIS_MODE_STRICT`, `ALDIS_MODE_LENIENT`); anomalies are a `uint32_t` mask, bit `n` for the flag with index `n` (`ALDIS_*_ANOMALY_*`).
- Two-phase writers are two stateless calls with the same arguments, `_writer_begin` and `_writer_finish`; no call keeps a pointer it is given (API-023, API-060).
- CUC fine time is `uint8_t[10]`, left-aligned, with its octet count; ASCII time codes are octet buffers without a NUL.
- The stateful helpers (`aldis_spp_tracker_t`, `aldis_spp_segmenter_t`, `aldis_spp_reassembler_t`) live in storage the caller provides, of `ALDIS_*_STORAGE_SIZE` octets aligned to `ALDIS_*_STORAGE_ALIGN` (8): declare it as a `uint64_t` array. `_init` checks it (CABI-031); every call checks the tag `_init` wrote and fails with `ALDIS_ERR_INVALID_HANDLE` on uninitialized, released, foreign, or moved storage (CABI-032). The SDU and the reassembly buffer are passed on every call.

```c
#include "aldis/aldis.h"

aldis_spp_packet_t view;
aldis_error_detail_t err;
int32_t rc = aldis_spp_decode(bytes, len, ALDIS_MODE_STRICT, &view, &err);
if (rc == ALDIS_ERR_INCOMPLETE) {
    /* err.needed octets are required */
}
```

## Files

- [`src/`](src/): one module per codec (`spp`, `spp_state`, `time`, `epp`), the pointer checks (`abi`), the handle storage (`handle`), the status codes (`error`), and two generated modules: `field` (`cargo xtask fields --write`) and `capacities` (`cargo xtask header --write`).
- [`capacities.toml`](capacities.toml): the engine capacities fixed when the library is built, which become `ALDIS_*_MAX_*` constants in the header and are reported by `aldis_limits` (CABI-030, GEN-011). Only the sections of helpers that have a C ABI are published: `[spp]` so far.
- [`cbindgen.toml`](cbindgen.toml): the header generator's configuration (CABI-002, CABI-003).
- [`tests/vectors.rs`](tests/vectors.rs): every live case of `test-vectors/{time,spp,epp}/` through the C ABI (M2 plan D4); [`tests/abi.rs`](tests/abi.rs): the argument, detail, and handle rules; [`tests/c/smoke.c`](tests/c/smoke.c): a C program against the libraries.

## The header

`include/aldis/aldis.h` is generated, committed, and never edited by hand (CABI-002). The generator is `cbindgen` 0.29.4 (MPL-2.0), pinned in `xtask/src/header.rs` and installed by the verification image; `cargo xtask header` refuses another version.

```sh
cargo install --locked cbindgen@0.29.4
cargo xtask header --write            # regenerate after changing src/ or capacities.toml
cargo xtask header                    # check: what the verify check `header` runs
cargo xtask header c-smoke cc c++     # libraries built; the header as C99 and C++11 (CABI-001, CABI-003)
```

On a merge conflict in the header, merge the sources and regenerate ([M2 plan](../../docs/milestones/m2-frame-codecs.md) §3).

## Features

| Feature | Effect |
|---|---|
| `std` (default) | Hosted builds, for ground systems |
| `panic-handler` | A minimal `#[panic_handler]` for `no_std` static-library builds. It only satisfies the linker: no panic path is reachable (GEN-020, VER-010) |
| `panic-unreachable` | A `#[panic_handler]` that calls the undefined `aldis_panic_is_unreachable`, for the exerciser's link check (VER-010). Not for integrators |

A bare-metal static library is built with:

```sh
cargo build -p aldis-ffi --no-default-features --features panic-handler \
            --target thumbv7em-none-eabihf --release
cargo xtask ffi-imports thumbv7em-none-eabihf   # needs nothing beyond memcpy/memset (CABI-004)
```

## Guarantees

This is the only library crate in which `unsafe` is allowed. Its lint table sets `unsafe_code` to `deny` instead of the workspace's `forbid`; every entry point and pointer check carries `#[expect(unsafe_code)]`, and every `unsafe` block a `// SAFETY:` comment (GEN-070, GEN-071). Every caller memory access goes through `abi.rs` and `handle.rs`. No heap, threads, or C runtime are required on `no_std` targets (CABI-004).

Verification: the C-ABI vector runner and `tests/abi.rs` on the host; Miri over both; the exerciser calls every exported function on the three bare-metal targets for the panic-freedom link check (M2 plan D16); the fuzz target `ffi_decode` compares the C ABI decoders with the Rust ones; `cargo xtask coverage` reports coverage without gating it (D16).
