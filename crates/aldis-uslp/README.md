# aldis-uslp

Frame codec for the CCSDS 732.1-B-3 Unified Space Data Link Protocol: USLP Transfer Frames on fixed-length and variable-length channels, truncated frames, the Transfer Frame Data Field header, OID frames, frame delimiting, and frame validation.

**Status:** implemented in Milestone 2 ([roadmap](../../docs/08-roadmap.md) §1, [M2 plan](../../docs/milestones/m2-frame-codecs.md) WP-5), modules 1–8: the UPID typed by a table generated from the SANA registry (`upid`), the channel configuration and its `VcLookup` (`config`), the Primary Header (`header`), the zero-copy decoder (`view`) and its truncated frames (`truncated`), the TFDF Header (`tfdf`), the one-shot, two-phase, truncated, and OID writers (`writer`), lenient-mode anomalies (`anomaly`), Frame Delimiting and Fill Data Removal (`delimit`), and the USLP Frame Validation Checks (`validate`). Module 9, its C ABI, is in `aldis-ffi` (`aldis_uslp_*`, [README](../aldis-ffi/README.md)); for it, `UslpFrameWriter::resume` takes up a frame begun with the same arguments without zero-filling the security fields, for a writer that keeps no state between its calls (API-023), and `encode_oid_galois` writes an OID frame from the Galois form of the generator (CMN-022).

## Example

```rust
use aldis_core::DecodeMode;
use aldis_core::security::SecurityLayout;
use aldis_uslp::{
    FrameContent, FrameDelimiter, FrameFields, FrameKind, MapConfig, PhysicalChannelConfig,
    SourceOrDestination, TfdfHeader, TfdzRule, TransferFrameType, TruncatedFrameLen, Upid,
    UslpMapId, UslpSpacecraftId, UslpVcId, VcConfig, VcParams, VcTable, encode, validate_frame,
};

// A variable-length channel (as over TC Synchronization and Channel Coding) with FECF; VC 4
// carries the non-truncated frames, VC 5 only truncated frames of 12 octets (OI-48).
let scid = UslpSpacecraftId::new(0x155).unwrap();
let (vcid, map) = (UslpVcId::new(4).unwrap(), UslpMapId::new(0).unwrap());
let truncated_vcid = UslpVcId::new(5).unwrap();
let pc = PhysicalChannelConfig::new(TransferFrameType::Variable, 1024, 0, true).unwrap();
let truncated = VcParams {
    truncated_frame_len: Some(TruncatedFrameLen::new(12).unwrap()),
    ..VcParams::new(TransferFrameType::Variable)
};
let channels = VcTable::<2, 1>::new(
    pc,
    &[
        VcConfig::new(scid, vcid, VcParams::new(TransferFrameType::Variable)).unwrap(),
        VcConfig::new(scid, truncated_vcid, truncated).unwrap(),
    ],
    &[MapConfig::new(scid, vcid, map, SecurityLayout::NONE)],
)
.unwrap();

// An expedited frame of one octet stream TFDZ; the Frame Length, the TFDF Header, and the FECF
// are computed.
let fields = FrameFields {
    spacecraft_id: scid,
    source_or_destination: SourceOrDestination::Destination,
    vc_id: vcid,
    map_id: map,
    kind: FrameKind::Expedited,
    vcf_count: 0,
};
let content = FrameContent {
    tfdf: TfdfHeader { rule: TfdzRule::OctetStream, upid: Upid::OctetStream },
    insert_zone: &[],
    ocf: None,
};
let mut unit = [0x55_u8; 16];
let n = encode(&channels, fields, content, &[1, 2, 3], &mut unit).unwrap();
assert_eq!(n, 13);

// At the receiving end: delimit the data unit, then validate each frame (732.1 §4.3.11).
let mut frames = FrameDelimiter::new(&unit, &channels);
let frame = frames.next().unwrap();
let uslp = validate_frame(frame.octets(), &channels, DecodeMode::Strict).unwrap();
assert_eq!(uslp.tfdz(), [1, 2, 3]);
assert!(!uslp.is_truncated());
assert_eq!(frames.count(), 1); // the three octets of 0x55 fill
```

## Where it sits

Layer 1 (codecs) of the [architecture](../../docs/01-architecture.md) §2. It depends only on `aldis-core`. The OCF is returned as an opaque `aldis_core::ocf::Ocf`; `aldis-tc` decodes a CLCW (CMN-011). The UPID table `src/upid/table.rs` is generated by `cargo xtask sana import uslp_protocol_id` from the committed snapshot [`specs/sana/uslp_protocol_id.tsv`](../../specs/sana/uslp_protocol_id.tsv) (M2 plan D13).
