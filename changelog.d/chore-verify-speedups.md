### Changed
- The hosted verification run builds xtask once and passes it to the other jobs, which install no Rust toolchain; `prepare` finds the image by a manifest lookup instead of pulling it (new `cargo xtask verify image --ref <repository>`). The header and the bare-metal library builds move to the `coverage` group, and the typical durations that order and balance a run are the means of three full hosted runs (VER-060, VER-067).
