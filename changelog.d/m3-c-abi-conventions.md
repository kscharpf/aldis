### Changed
- Specification only: the maintainer decided seven C ABI conventions on 2026-10-29 (one-shot encoders only, input enumerations as plain integers, `uint32_t` status codes, typed caller storage, no `struct_size` or `aldis_limits`, engine state accessed in place, engine inputs and actions as flat structs and tagged unions with `aldis_range_t` ranges). They are recorded in `docs/profiles/c-abi.md` section 12 and OI-57, with the spikes that checked them; CABI-040 is rewritten now, and the other rows change in the follow-up pull requests that implement each convention. OI-50 is superseded.
